# v0.1.0

The first release of the Azure SDK for Xo: the root module
(`github.com/xo-lang/azure`) and every module under it, 338 in all,
tagged v0.1.0 at one commit. Released with Xo 0.46.0; requires Xo 0.45.0
or later.

A community SDK for the Xo language. Not affiliated with or endorsed by
Microsoft. Microsoft and Azure are trademarks of the Microsoft group of
companies.

## What is in it

Coverage is from [docs/reports/azure-go-coverage.md](../reports/azure-go-coverage.md).

- **The core** (the root module): azcore v1.24.0's pipeline, policies,
  retries, errors, pagers, pollers, SAS-safe logging, SSE streaming, the
  cloud configurations and azcore's tracing layer.
- **azidentity v1.15.0**: every credential Go has (client secret,
  certificate, assertion, managed identity on every host including Arc
  and Service Fabric, workload identity with its proxy mode, Azure
  Pipelines, on-behalf-of, device code, interactive browser, username and
  password, and the developer tools az, azd and pwsh), the default and
  chained credentials, tenants, ADFS, CAE and the in-memory and
  caller-supplied token caches.
- **Data plane, 28 of Go's 36 library modules**, each at Go's latest
  release: Storage (azblob v1.8.3, azdatalake v1.7.1, azfile v1.7.2,
  azqueue v2.1.2), Cosmos DB (azcosmos v1.5.0), Tables (aztables
  v1.4.1), App Configuration (azappconfig v2.3.0), Service Bus
  (azservicebus v1.11.0), Event Hubs (azeventhubs v2.0.2), Event Grid
  (azeventgrid v1.0.0, aznamespaces v1.0.0, azsystemevents v1.1.0), Web
  PubSub (azwebpubsub v0.1.1), Key Vault (azsecrets v1.5.1, azkeys,
  azcertificates and azadmin v1.5.0), Monitor (azquery v1.2.0, query
  azlogs v1.2.0 and azmetrics v1.3.0, ingestion azlogs v1.1.0), Container
  Registry (azcontainerregistry v0.2.3), Batch (azbatch v0.1.0),
  tracing/azotel v0.4.0 (over std/trace) and Azure OpenAI's Azure types
  (azopenai v0.9.0, without openai-go).
- **Resource management: all 307 ARM modules**, generated from the specs
  Go's releases pin.

The versions above are Go's; every Xo module is v0.1.0.

## How it is checked

Every call of every client is compared with Go's own SDK: a Go program
runs the released Go module against a fake transport, and the Xo tests
replay the same calls and must produce Go's requests and results line for
line. No test calls Azure.

## Not in it

- azidentity/cache's per-OS protected storage (the keyring, keychain and
  DPAPI need std support first; decision 0012).
- The 7 data-plane modules Go marks deprecated.
- An OpenAI client for Azure OpenAI (azopenai has the Azure types only).

## Install

    xo get github.com/xo-lang/azure@v0.1.0
    xo get github.com/xo-lang/azure/azidentity@v0.1.0
    xo get github.com/xo-lang/azure/storage/azblob@v0.1.0

Get the modules your program uses; each requires the root at v0.1.0.

## Versions

Six modules list untagged milestones in their CHANGELOGs (azblob,
azdatalake, azfile, azqueue, azcosmos, aztables). They were steps of the
port, not releases: their `VERSION` constants (sent in the User-Agent)
are v0.1.0 now, and the milestones are kept under "Before the first
release".
